# Millennium English School (MES) — Official Website

Official website for **Millennium English School**, South Habra, North 24 Parganas, West Bengal 743263.

## 🌟 Overview

A modern, responsive, and accessible school platform built with React, TypeScript, and Tailwind CSS / custom design tokens.

- **7 Dedicated Pages / Sections**:
  - **Home**: Dynamic hero, "Why Millennium?", programs showcase, academic stages, campus facilities, and interactive enquiry modal.
  - **About Us**: School story, mission & vision, leadership principles, core values, and campus culture.
  - **Academics**: Complete curriculum stages (Toddler to High School), teaching philosophy, and co-curricular programs.
  - **Admissions**: 5-step admission workflow, eligibility criteria, required documents checklist, and FAQs.
  - **Notice Board**: Official announcements, circulars, and notifications with category filters and search.
  - **Events & Life at MES**: Annual Day (*CaNvAs*), Sports Day, Science & Art Exhibitions, Cultural celebrations, and interactive photo gallery.
  - **Contact & Location**: Interactive Google Maps embed, transport routes, office hours, and contact form.

## 🚀 Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Styling**: Vanilla CSS + Tailwind CSS utilities & organic doodle design tokens
- **Build Tool**: Vite + Oxlint

## 🛠️ Getting Started

### Prerequisites

- Node.js (v18 or newer recommended)
- npm / pnpm / yarn

### Installation

```bash
# Clone the repository
git clone git@github.com:meshabra/meshabra.git

# Navigate into project directory
cd meshabra

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
